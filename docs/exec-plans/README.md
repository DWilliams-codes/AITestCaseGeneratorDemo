# ExecPlan lifecycle

Use an ExecPlan for significant work as defined in [../PLANS.md](../PLANS.md).

- Name plans `TF-###-short-kebab-name.md`.
- Create the plan under `active/` before implementation.
- Keep the plan current when scope, contracts, or risk changes.
- Record observed verification and review evidence, not future intent.
- Move the same file to `completed/` only after its definition of done is met.
- Never use a completed plan as proof that later regressions cannot exist.

Active and completed plans are historical engineering evidence. Keep them free
of secrets, customer data, raw provider payloads, and personal information.
